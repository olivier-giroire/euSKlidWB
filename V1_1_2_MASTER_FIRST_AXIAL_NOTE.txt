euSKlidWB V1.1.2 patch

Base: euSKlidWB_v1_1_2_real_segments_collinear.zip supplied as reference.

Changes are intentionally limited to Sketcher export sequence constraints:
- The master spacing segment is selected from DSL creation order, not from geometric sorting.
- For each repeated spacing family, the first interval in the sequence is the master.
- The master remains the reference for length and Equal constraints.
- The dimension on the master is axial: DistanceY for vertical stepping, DistanceX for horizontal stepping.
- Existing tangency and collinearity logic is preserved.
- No Open Sketch, indicator, UV marker, zoom, or UI code was modified.
